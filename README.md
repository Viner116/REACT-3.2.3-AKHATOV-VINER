Тебе необходимо реализовать страницу со списком запусков SpaceX. Для этого создай репозиторий на GitHub со стеком Vite + React + TypeScript. Для облегчения работы со стилями и компонентами необходимо использовать библиотеку компонентов Mantine.

 

Макет и библиотека компонентов
Страница должна следовать следующему прототипу:



По клику на кнопку “See more” должно открываться модальное окно:



Для реализации верстки используй библиотеку Mantine:

Документация https://mantine.dev/guides/vite/

Для реализации карточки в списке используй компонент Card с пропсами shadow="sm" padding="md" radius="md" withBorder

 

API
API списка всех запусков: https://kata-spacex.onrender.com/api/launches 

 

Для отображения списка тебе понадобятся следующие поля:

launch.links?.mission_patch_small

launch.mission_name

launch.rocket?.rocket_name

 

Для модального окна:

launch.links?.mission_patch

launch.mission_name

launch.rocket?.rocket_name

launch.details

 

Комментарии:

необходимо добавить в проект StrictMode;

управление стейтом реализовать через useReducer, а не useState;

модальное окно должно быть реализовано с помощью Portal, а не компонента из Mantine или с помощью сторонней библиотеки;

придерживаться pixel perfect не нужно, макет должен визуально соответствовать скрину;

не забывай про типизацию ответа от сервера, пропсов и т.д.;

необходимо покрыть тестами основные сценарии приложения.
